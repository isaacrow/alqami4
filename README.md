# Alqami Spatial OPAC (علقمي للفهرسة الفراغية)

نظام فهرسة وببليوجرافيا مكانية ثلاثية الأبعاد وواقع معزز (3D AR) مبني وفق معيار بيبفرام 2.0 (BIBFRAME 2.0 Linked Data) للمخطوطات والنوادر والتراث الحضاري.

---

## الميزات الرئيسية (Key Features)

- **فهرسة بيبفرام متكاملة (BIBFRAME 2.0 Triad)**:
  - ربط كامل بين كيانات العمل (bf:Work)، التعبير (bf:Expression)، النسخة (bf:Instance)، والمقتنى (bf:Item).
  - تصنيفات مكتبة الكونغرس (LCC) وتصنيف ديوي العشري (DDC) ورؤوس موضوعات (LCSH).
  - سجلات أصيلة بصيغة Turtle / RDF.

- **استعراض ثلاثي الأبعاد تفاعلي (Interactive 3D Engine)**:
  - محرك ثلاثي الأبعاد عالي الأداء يعتمد على تقنية Google Model-Viewer و Draco Compression.
  - تمركز دقيق للمجسمات في المنتصف وتفاعل ناعم مع حركة مؤشر الفأرة (Mouse Move Turntable).
  - نقاط استكشاف دلالية (Interactive 3D Hotspots) مع شروحات تراثية متخصصة.

- **تجربة الواقع المعزز للهواتف (Mobile WebXR AR)**:
  - توليد تلقائي لرموز QR للدخول المباشر من الهاتف الذكي.
  - واجهة خاصة للهاتف تحتوي على بطاقة وصفية شاملة، نصوص الافتتاح والختام (Incipit & Explicit)، بيانات الكوديكولوجيا، ومحرر كود RDF مع إمكانية النسخ والتحميل.

- **تصميم فراغي مظلم زجاجي (Pitch Black & Glossy Glass)**:
  - واجهات سوداء نقية محسنة لشاشات OLED مع تأثيرات زجاجية مستوحاة من أجهزة الحوسبة الفراغية.
  - دعم كامل للغتين العربية والإنجليزية (Bilingual RTL/LTR).

## التشغيل والتطوير (Getting Started)

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm

### خطوات التثبيت والتشغيل
```bash
# تثبيت التبعيات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
